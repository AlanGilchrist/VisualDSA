OPERATION

Enter comma-separated integers. They are inserted in the given order, so the first key becomes the root. Keys must be unique.

Starting at the root, the key is compared with each node and moves left (smaller) or right (larger) until an empty position is found. Duplicates are rejected.

Try a leaf (20), a node with one child, and a node with two children (30 or 50) to see all three deletion cases.

Each comparison discards one subtree. Search for a present key (60) and an absent one (65).

Depth-first: every node is visited exactly once. Only the moment a node is output differs between the three orders.

Breadth-first search visits the tree level by level, from left to right. A first-in, first-out queue holds the nodes that have been discovered but not yet visited.
